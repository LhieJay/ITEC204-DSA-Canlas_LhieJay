        TechPulse Innovations — Startup IT Company

        1. Nature of Business

        TechPulse Innovations is an emerging software development startup specializing in mobile application development, web development, and cloud integration for local small and medium enterprises (SMEs).

        2. Number of Employees / Users

        • 1 Lead Software Architect / IT Administrator
        • 8 Software Engineers / Mobile Developers
        • 2 UI/UX Designers
        • 2 Project Managers
        • 2 Business Operations & Finance Staff
        • Total: 15 full-time employees

        3. Daily Operations

        • Software development and testing locally and on staging servers.
        • Daily standups, screen-sharing sessions, and real-time project management.
        • Regular transfer of graphical assets, application files, and client databases.
        • Remote access to company databases and code repositories.

        4. Computing Requirements

        • High-core processors and at least 32 GB RAM for developer machines.
        • Dedicated NAS for centralized file sharing and automated daily backups.
        • Gigabit wired connections and secure Wi-Fi 6 coverage.
        • Role-based access control, firewall rules, and endpoint protection.

        5. Current Problems (Assumed)

        • Mixed personal laptops cause crashes or slowdowns during heavy development work.
        • Personal cloud storage creates version confusion and security risks.
        • Unsecured Wi-Fi lacks proper firewall rules and network segmentation, exposing test databases.

        Security & Maintenance Plan

        • Password PolicyMinimum 12 characters, unique passwords, and immediate change if compromised.
        • Access ControlRole-based access with administrator privileges limited to the IT Administrator.
        • Endpoint ProtectionActive malware protection, scheduled scans, and current security updates.
        • FirewallRouter and workstation firewall rules to block unauthorized connections.
        • Network SegmentationSeparate guest wireless access from company resources and test systems.
        • Backup PolicyDaily NAS backup, weekly verification, and periodic offline backup.
        • Hardware MaintenanceClean systems, inspect cables, monitor temperatures and storage health.
        • Software UpdatesRegular OS, security, development-tool, and endpoint-protection updates.

        Maintenance Schedule

        ScheduleTask
        DailyCheck backups and security alerts.
        WeeklyCheck storage and system health.
        MonthlyClean workstations and review accounts and permissions.
        QuarterlyTest backup restoration and review network/firewall configuration.
        As neededApply security patches and replace failing hardware.

        Platform Evaluation

        PerformanceStrong processing, 32 GB RAM, NVMe storage, and gigabit networking support development workloads.
        ScalabilityMore workstations, storage, network ports, virtual machines, RAM, and bandwidth can be added.
        ReliabilityRAID 1, centralized backups, preventive maintenance, and endpoint protection improve reliability.
        SecurityRole-based access, passwords, firewalls, segmentation, endpoint protection, and backups reduce risk.
        Cost-EffectivenessHigher spending is focused on developer machines, NAS, network infrastructure, and security.
        Ease of MaintenanceStandardized workstations and centralized management make support easier.

        Possible Improvements

        • Increase NAS capacity as project files grow.
        • Add redundant internet connectivity for better availability.
        • Upgrade selected developer machines to 64 GB RAM for heavier workloads.
        • Add more Wi-Fi access points if the office expands.
        • Implement more advanced network monitoring.
        • Expand virtualization resources as the number of test environments increases.
